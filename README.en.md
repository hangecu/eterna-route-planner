# Eterna Route Planner

Unofficial interactive route planner for **The Life and Suffering of Prince Jerian**.

[Русский](README.md)

> The planner contains spoilers for events, choices, and their consequences.

## How to run

**Online:** [open Eterna Route Planner](https://hangecu.github.io/eterna-route-planner/).

**Offline:** download the ZIP from **Releases**, extract it, and open `index.html` in a browser.

No installation is required. Extract the archive before opening the planner.

## Features

- events and choices organized by chapter, with scene search and quick return to the current choice;
- Russian and English interface;
- visible conditions and consequences;
- automatic route recalculation;
- current characteristics, relations, and other state values;
- clicking an unavailable choice shows all earlier choices involving the characteristics listed in its conditions;
- clicking a characteristic or parameter in the header shows all earlier choices involving that value;
- annual projects and journeys;
- automatic local saving;
- route transfer through a JSON file;
- readable TXT memo export.

## Safety

The planner logic runs in your browser, separately from the game. The application does not send your route, contains no analytics, and requires no installer. Your route is stored only in the browser's local storage. The online page is served by GitHub Pages; the ZIP version can work fully offline. See [Security](SECURITY.md) and [Privacy](PRIVACY.md).
