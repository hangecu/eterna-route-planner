# История изменений

Здесь перечисляются основные изменения версий планировщика.

## 0.9.0-beta — 2026-08-28

- первая публичная тестовая версия планировщика;
- события и варианты выбора по ходу прохождения;
- переключатель русского и английского языка;
- отображение условий и последствий;
- автоматический пересчёт маршрута;
- поиск, навигация, локальное сохранение и экспорт в TXT;
- импорт и экспорт выбранного маршрута через JSON;
- локализованная ссылка на добровольную поддержку;
- ссылки добровольной поддержки для меню Sponsor на GitHub;
- проверка публикации на локальные пути, возможные секреты и служебные метаданные;
- запуск онлайн через GitHub Pages;
- автономный запуск через `index.html`.
