# Eterna Route Planner

Неофициальный интерактивный планировщик прохождения **The Life and Suffering of Prince Jerian**.

[English](README.en.md)

> В планировщике есть спойлеры к событиям, выборам и их последствиям.

## Как запустить

**Онлайн:** [открыть Eterna Route Planner](https://hangecu.github.io/eterna-route-planner/).

**Без интернета:** скачайте ZIP со страницы **Releases**, распакуйте его и откройте `index.html` в браузере.

Установка не нужна. Не запускайте файл прямо из архива — сначала распакуйте его.

## Что умеет планировщик

- показывает события и варианты выбора по главам;
- переключается между русским и английским языком;
- показывает условия выбора и его последствия;
- пересчитывает доступность следующих событий после изменения маршрута;
- показывает текущее состояние характеристик, отношений и других показателей;
- при нажатии на недоступный выбор позволяет просмотреть все предыдущие выборы, в которых участвовали указанные в условии характеристики;
- при нажатии на характеристику или параметр в шапке позволяет просмотреть все предыдущие выборы, в которых участвовал указанный параметр;
- учитывает ежегодные дела и поездки;
- автоматически сохраняет прогресс в браузере;
- позволяет перенести выбранный маршрут через JSON-файл;
- позволяет сохранить читаемую памятку в TXT.

## Безопасность

Логика планировщика работает в браузере и отдельно от игры. Приложение не отправляет выбранный маршрут, не содержит аналитики и не требует установщика.

Выбранный маршрут хранится только в локальном хранилище браузера. Онлайн-страницу предоставляет GitHub Pages; версия из ZIP может работать полностью без интернета. Подробнее: [безопасность](SECURITY.md) и [конфиденциальность](PRIVACY.md).
