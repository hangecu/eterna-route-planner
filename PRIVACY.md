# Приватность

Планировщик не собирает и не отправляет персональные данные.

## Локальные данные

В `localStorage` браузера сохраняются только:

- выбранные варианты маршрута;
- состояние свёрнутой или развёрнутой шапки;
- выбранный язык интерфейса.

Эти сведения остаются в профиле браузера на устройстве пользователя. В проекте нет собственного сервера, аналитики, рекламы, cookies, учётных записей или синхронизации.

Онлайн-версию предоставляет GitHub Pages. При открытии страницы запрос обрабатывает GitHub; согласно документации GitHub Pages, IP-адрес посетителя регистрируется в целях безопасности: <https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection>.

Версия из ZIP после открытия `index.html` не требует сети. Онлайн-версия и локальный файл имеют разные хранилища браузера, поэтому маршруты между ними автоматически не переносятся.

Экспорт создаёт JSON-файл только с выбранными вариантами или читаемую TXT-памятку. Импорт читает только явно выбранный пользователем JSON-файл и не загружает его в интернет.

Ссылка **«Поддержать»** открывает внешнюю страницу Tribute только после явного клика. До клика планировщик не обращается к Tribute. После перехода обработка данных выполняется Tribute по правилам этого сервиса.

## Удаление

Маршрут можно очистить кнопкой **«Сбросить выборы»**. Его также удаляет очистка локальных данных страницы в настройках браузера.
